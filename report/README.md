# Project Report: Compilation Guide

This folder holds the project report for EE 305 Electromagnetic Waves, Group 15 (Theme 4: *Machine-Learning-Based Transmission Line Fault and Load Identification*). The compiled version is `report.pdf`.

## Overleaf
1. Upload the whole `report/` folder (`main.tex`, `sections/`, `figures/`, `tables/`, `refs.bib`, `IEEEtran.bst`).
2. Compiler: **pdfLaTeX**. Root document: `main.tex`.
3. Click **Recompile**.

## Local
```bash
cd report
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```
`report/tables/` and `report/figures/` are regenerated by `4_evaluate.py` and `5_make_figures.py`.
