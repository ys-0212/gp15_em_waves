# TDR Dataset Documentation

This directory contains the synthetic training, validation, test, and out-of-distribution (OOD) datasets, alongside experimental laboratory Time Domain Reflectometry (TDR) measurements.

---

## 1. Synthetic Datasets

All synthetic traces are generated by `2_generate_data.py` using the exact frequency-domain cascade transmission line simulator (`tdr/simulator.py`).

### File Organization
- `train_quick.h5`, `train_quick_meta.parquet`: Training split (smoke-test / quick mode: 3,000 samples).
- `val_quick.h5`, `val_quick_meta.parquet`: Validation split (quick mode: 500 samples).
- `test_quick.h5`, `test_quick_meta.parquet`: Test split (quick mode: 500 samples).
- `ood_quick.h5`, `ood_quick_meta.parquet`: Five out-of-distribution subsets (quick mode: 100 samples per subset):
  1. `long_cable`: Cable lengths $l \in [250, 400]$ m.
  2. `high_loss`: Cable loss scale $s_{\text{loss}} \in [2.5, 4.0]$.
  3. `z0_shift`: Characteristic impedance shift $Z_0 \in [40, 45] \cup [55, 65]\ \Omega$.
  4. `slow_rise`: Generator rise time $t_r \in [5, 10]$ ns.
  5. `near_load`: Faults located within $0.5$ to $3.0$ m from load terminal.

### HDF5 & Parquet Structure
- `traces`: Shape `[N, 1024]`, clean step-response voltages $v(0, t)$ over $t/T_{\text{nom}} \in [0, 2.5)$ with the incident edge at $t/T_{\text{nom}} = 0.05$.
- Metadata columns:
  - `sample_id`: Unique integer ID.
  - `length_m`: Cable physical length in metres.
  - `z0`: Nominal characteristic impedance ($\Omega$).
  - `vf`: Velocity factor relative to $c$.
  - `loss_scale`: Frequency-dependent attenuation multiplier.
  - `rise_time_s`: Step voltage 10%–90% rise time in seconds.
  - `rg`: Source generator internal impedance ($\Omega$).
  - `v0`: Generator open-circuit step amplitude ($V$).
  - `v_inc`: Incident step plateau voltage at input terminal.
  - `fault_class`: Class label (`none, short, open, shunt_R, shunt_C, series_R, z0_section`).
  - `fault_class_id`: 0 to 6 integer encoding.
  - `fault_pos_m`, `fault_pos_frac`: Location of discontinuity in metres and fraction of cable length $d/l$.
  - `fault_val`: Numerical parameter ($R_f$, $C_f$, or $Z_0'$).
  - `load_class`: Class label (`open, short, matched, R, RL, RC`).
  - `load_class_id`: 0 to 5 integer encoding.
  - `load_R`: Load termination resistance ($\Omega$).
  - `load_tau_over_T`: Normalized reactive time constant $\tau / T_{\text{nom}}$.
  - `mask_loc`: 1 if fault $\ne$ `none`, 0 otherwise.
  - `mask_load`: 1 if fault $\notin \{\text{short}, \text{open}\}$, 0 otherwise.

## 2. Real Experimental Dataset: WISE-CASING

### Source & Attribution
- **Dataset:** Y. Wu and J. Wang (Lawrence Berkeley National Laboratory), *WISE-CASING: Time Domain Reflectometry Data from Lab Experiment on Coaxial Cable*, Geothermal Data Repository, submission 1164, 2018. DOI [10.15121/1559012](https://doi.org/10.15121/1559012).
- **Catalog pages:** <https://gdr.openei.org/submissions/1164>, <https://catalog.data.gov/dataset/wise-casing-time-domain-reflectometry-data-from-lab-experiment-on-coaxial-cable>
- **Documented setup (verbatim):** "The coaxial-cable experiment conducted in the lab was with 80 m coaxial cable( RG-85)." / "For the damaged cable, the damaged section is in the middle (40 m)." / "The amplitude of the data is mV with time (us)." Per-file resource descriptions are quoted verbatim in `real/wise_casing/labels.yaml`.

### What these records are, and how we use them
- The records are **pulse-type** TDR: the signal returns to ~0 between echoes, so they are not step responses. Our simulator and all three models use a **step** input, so the step-trained models are **not** applied to these records (that would be a domain mismatch).
- Instead, `tdr.data.analyse_real_wise_casing` performs a **physics consistency check** (experiment E8):
  1. measure the incident pulse peak $t_0$ and the strongest echo in each record (round trip $\Delta t$);
  2. estimate the velocity factor from the undamaged 80 m reference: $v_f = 2L/(c\,\Delta t)$;
  3. locate the damage by the velocity-free echo-time ratio $d = L\,\Delta t_{\text{damage}}/\Delta t_{\text{ref}}$ and compare with the documented 40 m;
  4. flag records whose echo time is inconsistent with their documented length.
- Results: `results/tables/real_data.md`, `results/tables/real_damage_localisation.md`, `figures/fig_real_data.png`.

### Documented inconsistencies (reported, not resolved)
- The main description says 80 m; the cutaway resource says "85m coaxial cable". We use 80 m.
- The termination echoes of the files documented as 20 m / 10 m / 5 m do not scale with those lengths at any single velocity (at the velocity estimated from the 80 m reference they correspond to roughly 80 m, 38 m and 13 m). These files are therefore excluded from velocity estimation; the file-to-resource mapping itself was checked against the dataset's own figure `3_cable_lengh_compare.pdf`.
