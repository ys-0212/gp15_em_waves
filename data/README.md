# TDR Dataset Documentation

This directory contains the synthetic training, validation, test, and out-of-distribution (OOD) datasets, alongside experimental laboratory Time Domain Reflectometry (TDR) measurements.

---

## 1. Synthetic Datasets

All synthetic traces are generated by `2_generate_data.py` using the exact frequency-domain cascade transmission line simulator (`tdr/simulator.py`).

### File Organization
- `train_quick.h5`, `train_quick_meta.parquet`: Training split (smoke-test / quick mode: 3,000 samples).
- `val_quick.h5`, `val_quick_meta.parquet`: Validation split (quick mode: 500 samples).
- `test_quick.h5`, `test_quick_meta.parquet`: Test split (quick mode: 500 samples).
- `ood_quick.h5`, `ood_quick_meta.parquet`: Five out-of-distribution subsets (quick mode: 100 samples per subset):
  1. `long_cable`: Cable lengths $l \in [250, 400]$ m.
  2. `high_loss`: Cable loss scale $s_{\text{loss}} \in [2.5, 4.0]$.
  3. `z0_shift`: Characteristic impedance shift $Z_0 \in [40, 45] \cup [55, 65]\ \Omega$.
  4. `slow_rise`: Generator rise time $t_r \in [5, 10]$ ns.
  5. `near_load`: Faults located within $0.5$ to $3.0$ m from load terminal.

### HDF5 & Parquet Structure
- `traces`: Shape `[N, 1024]`, clean step-response voltages $v(0, t)$ over $t/T_{\text{nom}} \in [0, 2.5)$ with the incident edge at $t/T_{\text{nom}} = 0.05$.
- Metadata columns:
  - `sample_id`: Unique integer ID.
  - `length_m`: Cable physical length in metres.
  - `z0`: Nominal characteristic impedance ($\Omega$).
  - `vf`: Velocity factor relative to $c$.
  - `loss_scale`: Frequency-dependent attenuation multiplier.
  - `rise_time_s`: Step voltage 10%–90% rise time in seconds.
  - `rg`: Source generator internal impedance ($\Omega$).
  - `v0`: Generator open-circuit step amplitude ($V$).
  - `v_inc`: Incident step plateau voltage at input terminal.
  - `fault_class`: Class label (`none, short, open, shunt_R, shunt_C, series_R, z0_section`).
  - `fault_class_id`: 0 to 6 integer encoding.
  - `fault_pos_m`, `fault_pos_frac`: Location of discontinuity in metres and fraction of cable length $d/l$.
  - `fault_val`: Numerical parameter ($R_f$, $C_f$, or $Z_0'$).
  - `load_class`: Class label (`open, short, matched, R, RL, RC`).
  - `load_class_id`: 0 to 5 integer encoding.
  - `load_R`: Load termination resistance ($\Omega$).
  - `load_tau_over_T`: Normalized reactive time constant $\tau / T_{\text{nom}}$.
  - `mask_loc`: 1 if fault $\ne$ `none`, 0 otherwise.
  - `mask_load`: 1 if fault $\notin \{\text{short}, \text{open}\}$, 0 otherwise.

## 2. Real Experimental Dataset: WISE-CASING

### Source & Attribution
- **Dataset:** *WISE-CASING: Time Domain Reflectometry Data from Lab Experiment on Coaxial Cable*
- **Sponsor / Host:** U.S. Department of Energy (DOE) Geothermal Data Repository (GDR), OpenEI Submission 1164.
- **Permanent DOI:** [10.15121/1559012](https://doi.org/10.15121/1559012)
- **OSTI ID:** 1559012
- **Authors:** Yuxin Wu, Jiannan Wang (Lawrence Berkeley National Laboratory).
- **Licence:** Creative Commons Attribution / Public Domain (U.S. Government work).

### Experimental Setup & Physical Parameters
- **Cable Specification:** 80–85 m RG-85 coaxial cable (polyethylene dielectric, nominal velocity factor $v_f = 0.66$). Additional tests on shorter segments of 20 m, 10 m, and 5 m.
- **Instrument Output:** Time in microseconds ($\mu\text{s}$) with uniform sampling $\Delta t = 0.001\ \mu\text{s}$ (1.0 ns), and signal amplitude in millivolts ($\text{mV}$).
- **Damage Configuration:** A $120^\circ$ physical circumferential cutaway applied at $d = 40$ m along an 85 m cable, representing severe localized shield degradation / structural damage. All tests terminated in shorted conditions.

### Traces & Ground Truth (`labels.yaml`)
1. `TDR_20180315194711u.csv`: 85 m undamaged baseline cable with shorted termination.
2. `TDR_20180315195720u.csv`: 85 m cable with $120^\circ$ cutaway anomaly at $d = 40$ m and shorted termination.
3. `TDR_20180404134819u.csv`: 20 m undamaged cable with shorted termination.
4. `TDR_20180404135441u.csv`: 10 m undamaged cable with shorted termination.
5. `TDR_20180404141951u.csv`: 5 m undamaged cable with shorted termination.

### Processing Assumptions & Normalization (`load_real_wise_casing`)
1. **Velocity Factor:** Assumed $v_f = 0.66$ based on polyethylene RG-85 specifications, giving propagation speed $u = 0.66 \times c \approx 1.979 \times 10^8$ m/s.
2. **Time Mapping:** The nominal round-trip time is computed as $T_{\text{nom}} = 2l/u$. The incident edge time $t_{\text{inc}}$ is identified in the raw recording ($t \approx 0.050\text{--}0.064\ \mu\text{s}$). The physical time axis is mapped to normalized dimensionless units $t/T_{\text{nom}} = 0.05 + (t - t_{\text{inc}})/T_{\text{nom}}$.
3. **Resampling:** Uniform linear interpolation is performed across 1024 points over $t/T_{\text{nom}} \in [0, 2.5)$, aligning the physical incident pulse exactly with the synthetic training convention at $t/T_{\text{nom}} = 0.05$.
4. **Voltage Normalization:** The instrument's baseline level prior to launch ($V_{\text{base}}$) is mapped to 0.0, and the initial transmission line propagation plateau ($V_{\text{plat}}$) is mapped to 1.0 via $\tilde{v} = |V(t) - V_{\text{base}}| / |V_{\text{plat}} - V_{\text{base}}|$.
